# Codex 迁移助手 0.3.5 预览版

## 这版保存什么

默认保护重装系统后不会自动回来的内容：本地会话索引与转录、会话关联的项目源码和 Git 元数据、个人技能、记忆库、插件，以及承载个人状态或自定义路径的配置。Codex / ChatGPT 程序和安装目录不备份；会话主数据目录中的已知顶层日志、缓存、临时锁、沙箱运行文件和登录令牌也会自动排除。无法识别的内容继续保留，避免误漏个人资料。

账号登录、云端权限、组织策略、Windows 凭据和已安装的开发环境不能靠复制文件自动恢复。新系统仍需重新安装软件、登录账号和安装项目依赖。

## 备份步骤

1. 启动程序并阅读风险提示。
2. 进入“备份”，点击“一键扫描并推荐”。程序会读取实际 `CODEX_HOME`、`CODEX_SQLITE_HOME`、配置引用和各磁盘中的项目位置，并自动选择推荐范围。
3. 查看“当前判定”“推荐备份范围”和“官方旧配置检查”。如果提示缺少会话或项目文件，按提示定位后重新扫描。
4. 选择另一块物理介质上的保存位置，勾选核对框，点击“开始备份并验证”。
5. 到“检查”页再次验证备份包。验证和试恢复完成前不要清空旧系统。

通常不需要逐条选择。只有想排除部分内容时，才展开“我要自己调整”。会话页默认按项目目录分组，同一目录只显示一次；勾选项目会一次选择目录下全部会话，方框显示横线表示只选择了一部分。展开项目可以查看或调整单条会话，“按单条会话查看”保留原来的状态筛选。无论从哪种视图选择，会话都会同步关联它的对话文件、项目源码和 Git 依赖。自定义 Windows 用户目录和额外盘符位于“高级扫描设置”，抢救模式与密码保护位于“高级备份设置”。

## 官方旧配置检查

工具依据当前 OpenAI 官方配置参考，对已经读取的配置做只读检查：

- “已不支持”表示原文件仍会备份，但新系统启用前必须改为官方替代项。
- “已弃用”表示目前可能仍兼容，建议尽快迁移到新设置。
- “旧名称”表示官方已有新名称，工具会列出对应关系。
- “官方未确认”表示资料不足，不能据此删除；文件仍会保留和备份。

这项检查不会编辑配置，也不会把任何文件自动当作垃圾清理。

## 归档清理

“清理”页签可以在备份前安排清理项，但只有本次运行成功生成且验证的备份确实覆盖候选后，执行按钮才会启用。

- 低风险项：`bin`、`obj`、`node_modules`、缓存和构建输出等可重建目录。批量按钮只选择这些项。
- 高风险项：归档会话引用的整个项目位置，即使没有 Git 或构建标记也会显示。它可能包含源码或其他人工文件，显示红色，必须逐项手动勾选。
- 锁定项：仍被活动会话使用，或与活动项目存在父子目录关系，不允许清理。

清理不会永久删除，而是移动到同盘 `.codex-backup-quarantine` 隔离目录并生成 `cleanup-journal.json`。可在同一页使用“按隔离日志还原”；如果原位置已经重新出现，工具不会覆盖。

## 恢复边界

恢复前先验证整个包，再选择原布局、新文件夹或隔离解出。系统级配置只恢复到隔离位置供核对，不直接写入 `ProgramData`。恢复后必须手动确认登录、侧栏会话、项目源码、Git 分支、未提交修改、技能、记忆和代表性项目运行。
