# Codex 迁移助手 0.3.5 预览版

## 这版保存什么

默认保护重装系统后不会自动回来的内容：本地会话索引与转录、会话关联的项目源码和 Git 元数据、个人技能、记忆库、插件，以及承载个人状态或自定义路径的配置。Codex / ChatGPT 程序、安装目录、应用缓存和普通日志不作为独立必选项；如果它们位于一个被整体保存的个人数据根目录内，可能随父目录一并进入备份。

账号登录、云端权限、组织策略、Windows 凭据和已安装的开发环境不能靠复制文件自动恢复。新系统仍需重新安装软件、登录账号和安装项目依赖。

## 备份步骤

1. 启动程序并阅读风险提示。
2. 进入“备份”，点击“重新扫描”。程序会读取实际 `CODEX_HOME`、`CODEX_SQLITE_HOME`、配置引用和各磁盘中的项目位置。
3. 在顶部页签中分别检查“会话、项目、记忆、配置、技能、插件工具、其他”。页签显示“已选 / 总数”。
4. 在会话页按活动、归档、缺失关联或归档残留筛选。勾选会话会联动其转录、项目源码、Git 依赖和必需个人数据。
5. 选择另一块物理介质上的备份位置，开始备份并等待逐文件校验完成。
6. 到“检查”页再次验证备份包。旧系统不得在验证和试恢复前清空。

## 归档清理

“清理”页签可以在备份前安排清理项，但只有本次运行成功生成且验证的备份确实覆盖候选后，执行按钮才会启用。

- 低风险项：`bin`、`obj`、`node_modules`、缓存和构建输出等可重建目录。批量按钮只选择这些项。
- 高风险项：带 Git 或构建项目标记的整个归档项目，包含源码，显示红色，必须逐项手动勾选。
- 锁定项：仍被活动会话使用，或与活动项目存在父子目录关系，不允许清理。

清理不会永久删除，而是移动到同盘 `.codex-backup-quarantine` 隔离目录并生成 `cleanup-journal.json`。可在同一页使用“按隔离日志还原”；如果原位置已经重新出现，工具不会覆盖。

## 恢复边界

恢复前先验证整个包，再选择原布局、新文件夹或隔离解出。系统级配置只恢复到隔离位置供核对，不直接写入 `ProgramData`。恢复后必须手动确认登录、侧栏会话、项目源码、Git 分支、未提交修改、技能、记忆和代表性项目运行。
