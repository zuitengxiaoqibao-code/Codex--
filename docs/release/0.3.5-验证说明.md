- 范围回归：会话、项目、技能、记忆和必要个人配置保持保护；可重新安装的应用来源既不是必须项，也不默认选择。会话主数据根会自动排除已知顶层日志、缓存、临时锁、沙箱运行状态和登录令牌，并保留项目目录中的同名文件。
