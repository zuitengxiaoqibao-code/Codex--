# 0.3.5 验证说明

- 源码回归：150 项通过，0 失败，0 跳过。
- Release 构建：0 警告，0 错误。
- WPF 压力 smoke：窗口、8 个页签和导航可实例化；1,000 个会话批量取消并恢复、单个会话点击和共享项目来源点击在 Dispatcher 空闲后仍保持响应。
- 选择回归：共享项目直到最后一个关联会话取消后才释放；复选框只改变内存中的备份范围和可见计数，不访问磁盘、不刷新整张表、不重建问题列表，也不安排延迟完整性检查。完整检查只在用户点击“重新检查是否齐全”或开始备份时执行。

- 范围回归：会话、项目、技能、记忆和必要个人配置保持保护；可重新安装的应用来源既不是必须项，也不默认选择。会话主数据根会自动排除已知顶层日志、缓存、临时锁、沙箱运行状态和登录令牌，并保留项目目录中的同名文件。
- 清理回归：低风险构建目录、完整归档项目、活动项目锁定、嵌套活动项目锁定、备份覆盖门禁、隔离和按日志还原均有自动测试。
- 当前机器只读扫描识别 Codex `26.908.4834.0`、839 个来源、642 个独立会话、644 条会话关联、105 个项目位置和 71 条发现；7 个可重新安装应用来源均非必选且不默认选择。4 个归档会话项目均显示为红色高风险候选。
- 发布 EXE 需通过 self-test、WPF smoke、PowerShell 发布校验、UTF-8 扫描和 SHA-256 核对。

真实 Codex 应用层恢复、干净 Windows 重装、账号重新登录、侧栏会话显示和代表性项目运行仍需在真实新系统验收，因此版本保持 preview。
