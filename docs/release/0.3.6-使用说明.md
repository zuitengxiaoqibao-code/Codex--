# Codex 迁移助手 0.3.6 预览版

## 先知道这件事

本工具只为重装系统前的个人资料迁移服务。它默认保护本地会话索引与转录、会话关联的项目源码和 Git 信息、技能、记忆库、插件及个人配置。Codex / ChatGPT 程序、安装目录、普通日志、缓存、临时锁、沙箱运行文件和登录令牌不会默认备份；新系统需要重新安装程序和重新登录。

备份包的完整性、会话与项目路径的关联、以及新系统里应用能否正常显示会话是三项独立的验收。完成文件校验不代表已经完成真实新系统验收，所以旧盘在全部核对前不能格式化。

## 最简单的备份方式

1. 启动程序，阅读欢迎页的风险提示，勾选确认后进入迁移助手。
2. 在左侧选择“备份个人数据”，点击“一键扫描并推荐”。工具会读取实际 `CODEX_HOME`、SQLite 状态、配置引用和各盘符中的项目位置；扫描不会移动、删除或改写文件。
3. 查看“当前判定”和“推荐备份范围”。如果出现会话缺少项目、转录或路径的提示，先按提示定位，再重新扫描。
4. 大多数情况下无需逐条选择。会话默认按项目目录分组，勾选一个项目会选择该目录下全部会话；半选表示只选择其中一部分。会话选择会同步关联的对话文件、项目源码和 Git 依赖。
5. 如果要调整范围，展开“我要自己调整”。选择只改变本次备份范围，不会重新扫描磁盘，也不会延迟执行完整性检查。完整检查只会在你主动检查或开始备份时执行。
6. 选择另一块物理介质上的保存位置，完成核对后开始备份。完成后到“检查与验收”页验证包，再保留一份独立副本。

## 新的操作结构

- 左侧的四步导航始终显示当前所在步骤；风险确认前不会启用。
- 底部固定操作栏显示当前动作：备份页为“开始备份”，恢复页为“执行恢复”，检查页为“扫描当前环境”。
- 项目分组是会话选择的默认入口。只在需要排除个别会话时展开项目或切换到“按单条会话查看”。
- “清理”只会隔离已经被本次成功备份且通过校验覆盖的候选，绝不直接永久删除。

## 恢复边界

恢复前先验证包，再执行恢复预演，并确认原布局、新文件夹或隔离解出的目标路径。系统级配置只恢复到隔离位置供检查，不会直接写入 `ProgramData`。恢复后手动确认账号登录、侧栏中的活动和归档会话、项目源码、Git 分支和未提交修改、技能、记忆库、插件及代表性项目运行。

本版本为预览版：合成数据往返和当前机器只读扫描已验证；真实全新 Windows、真实 Codex 应用层会话显示和代表性项目运行必须由重装后的人工验收完成。
