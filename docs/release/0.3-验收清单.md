# Codex 迁移助手 0.3 预览版验收清单

## 已自动验证

- 源码回归测试全部通过。
- WPF 项目以 .NET 10 Windows x64 自包含方式发布。
- EXE 自检和界面导航 smoke 通过。
- 普通目录包逐文件 SHA-256、清单和 SQLite inventory 可复核。
- 密码保护包支持错误密码和篡改拒绝；密码不写入清单或报告。
- 多套 Core 必须明确主 Core；未知或不一致的目标版本阻止受控替换。
- 会话、项目、转录、Git 指针和记忆库指针分别验收；结构通过不代表应用已登录可用。

## 重装前操作

1. 退出 Codex、终端任务、桥接工具和可能写入数据的外围程序。
2. 重新扫描；只有显示“可以重装”且备份包二次校验通过，才把它当作重装前候选。
3. 至少保存两份备份，放在不同物理介质；不同盘符不一定代表不同硬盘。
4. 如果使用加密包，离线保存密码；遗失密码没有恢复路径。
5. 保留旧磁盘或系统镜像，直到新系统完成应用层验收。

## 新系统验收

- 安装与来源版本兼容的 Codex；目标版本未知时先保持隔离恢复。
- 选择正确的主 Core；其他 Core 单独保存，不能合并数据库。
- 检查登录、侧栏会话、代表性会话正文、项目工作目录和 Git 分支。
- 检查记忆库指针实际可读；逐项审核技能、插件、自动化和外围工具后再手动启用。
- 在至少一个代表性项目中运行既有测试或启动命令。工具不会替用户执行未知脚本。
- 只有结构验收和应用层验收都完成，才考虑清理 `.stage`、`.original`、`.rollback`、`.undo` 和旧系统副本。

## 官方资料边界

官方 Codex 仓库的 `docs/config.md` 说明配置由 `config.toml` 和受管 `requirements.toml` 层组成，并指向在线配置参考。在线页面可能受访问控制影响；本工具只使用本机已读取、可校验的字段，未知字段进入人工核查，不会猜测恢复。
