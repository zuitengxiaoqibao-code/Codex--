# 按项目目录选择会话设计

## 目标

让普通用户按熟悉的项目目录选择会话。同一个项目目录只在主列表显示一次，勾选该项目即可选中目录下的全部会话；需要精细调整时再展开项目，单独选择会话。

## 方案比较

1. **项目目录卡片并可展开会话（采用）**：主层信息最少，支持整组选择，同时保留单条调整能力。与 Codex 侧栏的“项目下包含会话”结构接近。
2. **先选目录、再显示会话**：界面更简单，但用户无法同时比较多个项目，也不容易发现某个项目存在缺失关联。
3. **继续使用会话表并增加目录筛选**：改动较小，但大量未命名会话仍占据主视图，没有解决重复和混乱。

## 默认界面

会话页默认显示“按项目目录选择”。每个项目卡片包含：

- 项目名称：取项目目录最后一级名称；无法识别时显示“未识别项目”。
- 完整目录：作为较小的辅助信息，便于确认同名项目。
- 选择状态：全选、部分选择、全不选三态。
- 摘要：已选会话数、总会话数、活动、归档、状态未知和缺失关联数量。
- 展开入口：默认收起；展开后显示该项目下的会话标题、状态、最近活动和提醒。

点击项目复选框时，一次选中或取消该项目下全部会话。部分选择状态点击后恢复为全选。单条会话选择仍沿用现有内存关联索引，联动对话正文、项目源码和 Git 依赖。

保留“按单条会话查看”入口，用于按标题、状态和异常精细筛选。它默认隐藏，不再作为主要操作界面。

## 分组规则

- 使用会话元数据中已经发现的项目目录分组，不重新扫描磁盘。
- 路径比较忽略大小写并使用标准化完整路径；同一路径的不同写法归为一组。
- 同一会话若记录了多个不同项目目录，会出现在对应的多个项目组中；它仍是同一个选择对象，在任一组选择都会同步其他组状态。
- 没有项目目录的会话归入单独的“未识别项目”组，并以黄色或红色提示人工核对。
- 项目组按最近活动时间倒序排列；未识别项目放在最后。

## 性能与安全

- 分组只在扫描完成后基于内存中的会话记录建立一次。
- 项目或会话勾选只更新内存选择、引用计数和可见摘要，不访问文件系统，不运行完整性检查。
- 搜索和项目状态筛选只刷新项目组视图，不刷新来源表或问题列表。
- 完整性检查仍只在用户主动点击检查或开始备份时执行。

## 验证

- 单元测试覆盖同目录合并、路径大小写、未识别项目、多目录会话、排序和三态选择摘要。
- WPF smoke 验证项目视图默认可见、单条会话视图默认隐藏、项目组批量选择和 1,000 会话性能。
- 发布前继续运行全量测试、Release 构建、发布 EXE self-test、真实只读扫描、UTF-8 检查、PowerShell 5.1 发布校验和便携包解压自检。
